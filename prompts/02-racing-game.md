# 02 · 俯视角街机赛车游戏

## Prompt

```
Make a complete, polished browser game in one HTML file: a top-down arcade racing game with 3 tracks, AI opponents that take different racing lines, drifting with tire marks and particles, a lap timer, a best-lap leaderboard, a start menu, and synthesized sound effects using the Web Audio API. No external assets; draw everything with code. It should feel fun to play, not like a demo.
```

## 考察点
- 完整游戏流程（菜单 → 倒计时 → 比赛 → 结算 → 排行榜）
- 车辆物理与漂移手感
- AI 走线差异与超车行为
- Web Audio 合成音效
- "好玩而不是 Demo"的整体打磨程度
